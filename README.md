# ZwScreenshot

A lightweight Windows screenshot tool with a tray icon, global shortcuts, and a built-in library for quick markup.

## What it does

- Capture a region, a single screen, or the whole desktop
- Capture a browser tab (Chrome or Edge), or re-shoot a pinned area or your last region
- Mark up shots with outline, highlight, and blackout tools
- Auto-save to PNG, JPEG, or BMP and copy to the clipboard
- Seven themes: Midnight, Lagoon, Petal, Cobalt, Ember, Moss, Paper

## How to use it

1. Run `zwscreenshot.exe`, or install it with `ZwScreenshot-Setup.msi`.
2. Press `Ctrl + Alt + Shift + F6` to capture a region, or `Ctrl + Alt + Shift + F7` to capture a screen.
3. Drag over what you want, release, then paste with `Ctrl + V`.

Shortcuts can be changed in Preferences → Shortcuts. Right-click the tray icon for more options, or choose Exit to quit.

## Requirements

Windows 10 (version 2004 or newer).
